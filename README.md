# Бот для проверки подписки на Telegram-каналы

Полнофункциональный Telegram-бот для проверки подписки пользователей на указанные каналы. Бот предоставляет доступ к контенту только после подтверждения подписки.

## ✨ Возможности

- ✅ Проверка подписки на несколько каналов одновременно
- ✅ Динамические кнопки подписки для каждого канала
- ✅ Повторная проверка подписки при каждом действии
- ✅ Красивые инлайн-кнопки и меню
- ✅ Обработка ошибок и уведомления пользователя
- ✅ Защита от отписки после получения доступа

## 🚀 Установка

### Предварительные требования

- Python 3.7 или выше
- Аккаунт в Telegram
- Созданный бот через [@BotFather](https://t.me/BotFather)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/thetemirbolatov/subscription-bot.git
cd subscription-bot
```

2. Установите необходимые зависимости:
```bash
pip install pytelegrambotapi
```

3. Настройте бота (см. раздел [Настройка](#настройка))

## ⚙️ Настройка

1. Получите токен бота у [@BotFather](https://t.me/BotFather)
2. Откройте файл `subscribe.py` в текстовом редакторе
3. Найдите строку и замените токен:
```python
TOKEN = 'your_token_here'
```

4. Настройте список каналов для проверки:
```python
CHANNELS = [
    "@your_channel_username",
    "-1001234567890",  # или ID канала
]
```

**Важно:** Бот должен быть администратором во всех указанных каналах!

## 🎮 Использование

### Запуск бота

```bash
python subscribe.py
```

### Команды бота

- `/start` - начать работу с ботом, проверить подписку

### Процесс работы

1. Пользователь запускает бота командой `/start`
2. Бот проверяет подписку пользователя на все указанные каналы
3. Если пользователь не подписан, бот показывает кнопки для подписки
4. После подписки пользователь нажимает "✅ Я подписался"
5. Бот проверяет подписку и предоставляет доступ к основному меню
6. Пользователь может получить контент через меню

## 📁 Структура кода

```python
subscribe.py
├── Настройки (TOKEN, CHANNELS)
├── Вспомогательные функции
│   ├── check_subscription() - проверка подписки
│   ├── main_menu_keyboard() - клавиатура главного меню
│   └── subscription_keyboard() - клавиатура для подписки
├── Обработчики сообщений
│   ├── start() - обработчик команды /start
│   └── callback_handler() - обработчик кнопок
└── Запуск бота
```

### Основные функции

#### `check_subscription(user_id)`
Проверяет статус подписки пользователя на все каналы. Возвращает `True`, если пользователь подписан на все каналы.

#### `main_menu_keyboard()`
Создает клавиатуру главного меню, которая появляется после успешной проверки подписки.

#### `subscription_keyboard()`
Создает клавиатуру с кнопками для подписки на каждый канал и кнопкой проверки подписки.

## ❓ FAQ

### ❓ Как получить ID канала?
1. Добавьте бота [@username_to_id_bot](https://t.me/username_to_id_bot) в канал
2. Отправьте в канале любое сообщение
3. Перешлите это сообщение боту
4. Бот покажет ID канала (отрицательное число, например: -1001234567890)

### ❓ Почему бот не видит подписку?
- Убедитесь, что бот является администратором канала
- Проверьте правильность username или ID канала
- Убедитесь, что пользователь действительно подписался

### ❓ Как добавить больше каналов?
Просто добавьте новые каналы в список `CHANNELS`:
```python
CHANNELS = [
    "@channel1",
    "@channel2",
    "-1001234567890",
    "@channel3"
]
```

### ❓ Как изменить текст сообщений?
Найдите соответствующие строки в функциях `start()` и `callback_handler()` и измените текст на свой.
